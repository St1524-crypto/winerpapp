# 獎金制度標準（2026-11-13 確認）
所有獎金以「獎勵點」計，非新台幣。小數一律捨去。
## 共同
- 發放：80% 現金錢包、20% 貢獻點；結算後 7 天發放。
- 月責任額 200 點；須有效 VIP、未被設定不參與分紅。
- 獎勵點來自已付款訂單商品獎勵點；「不發獎勵點」訂單不計；tier_reward_points=0 即為 0。
- 刪單/取消/退款/部分退貨（按比例）自動扣回當月點數。
- 位階門檻：V800 / S3500 / T9000 / E21000 / A35000。升級須買套組累計獎勵點。
## 日結（自動；結算前一日；目前正式站「下次結算時間」顯示 台北 03:00，與口頭 13:00 不一致，待使用者確認）
1. 復購（消費回饋）：訂單獎勵點 × 第1代5%、第2代5%、第3代0%。
2. 推薦級差：V5% S10% T20% E40% A/一~七星/董事50%，往上取差額，累計至50%。
3. 消費分紅 POOL_VSTEA：限E/A，5%均分；90天內須推薦1人或在專屬名單；上限 E 36,800、A 68,000。
4. 營業分紅 POOL_123（一~五星）5%；POOL_67D（六、七星、董事）5%；均分；累計上限 一星88,000、二星268,000、三星368,000、四星468,000、五星1,568,000、六星2,668,000、七星3,768,000、董事5,868,000（2026-11-13 使用者確認，含五星1,568,000）。上限為「個人總收益」：所有獎金（未取消）＋所有分紅池實發＋升級推薦獎金合計；達上限停發，最後一次補到剛好上限。
## 月結（系統設定：手動模式 monthly_bonus_mode=manual、結算日=每月1日結算上月；須管理員執行）
1. VIP月獎金：本人+第一代當月點數；門檻 10,000→5%、20,000→7%、30,000→8%、50,000→9%、100,000→10%；未達10,000為0。
2. 超額回饋：(當月個人點數−200)×位階比例 V5 S10 T20 E40 A/星級50%。
3. 位階級差：往上找比例更高且當月達200點者，取比例差，累計至50%，最多50層。
4. 月度復購、全國分紅（五~七星、董事，各級池=當月總點數×2%均分；年上限 20萬/30萬/40萬/50萬；2026-07-16 起生效）。
## 規則
- 計算、報告、修改前先讀正式站設定與本文案比對；不一致時先回報使用者確認，不自行改。
- 使用者修改制度時，同步更新本文案。

## 正式站核對紀錄（2026-11-13）
- 一致：位階門檻、推薦級差、超額回饋比例、復購5/5/0、月獎金門檻、分紅池比例與適用位階、E/A上限、一星~董事上限、全國分紅2%與年上限、責任額200、7天自動發放。
- 不一致待確認：日結時間（設定 03:00 vs 文案 13:00）。
