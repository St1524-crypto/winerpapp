# winerp 獎金制度標準

1. 先讀 references/rulebook.md（完整制度文案，唯一標準）。
2. 計算或報告前，查正式站設定（制度設定、分紅池、位階門檻、上限）與文案比對；不一致先回報使用者確認，不可自行更改。
3. 固定規則：獎金一律以獎勵點計（非新台幣）；發放 80% 現金、20% 貢獻點同批；7 天後發放；月責任額 200 點；小數捨去；不發獎勵點訂單不計；刪單/取消/退款/部分退貨自動扣回。
4. 會員一律用會員編號比對，不用姓名。
5. 使用者改制度後，同步更新本 skill 的 rulebook.md、docs/bonus-rulebook.md 與記憶文案。
6. 回報須含「問題原因」與「避免重覆對策」。
